# CyriMarket — Application Android

WebView Android qui charge https://cyrimarket.liveblog365.com/
Aucune donnée stockée localement — tout vient du serveur.

## Obtenir l'APK via GitHub (sans Android Studio)

1. Crée un compte sur **github.com** (gratuit)
2. Crée un nouveau dépôt : `New repository` → nom : `cyrimarket-app` → Public → Create
3. Téléverse ce dossier entier dans le dépôt (bouton `uploading an existing file`)
4. Va dans l'onglet **Actions** → clique sur `Build CyriMarket APK` → **Run workflow**
5. Attends ~5 minutes → clique sur le workflow terminé → télécharge **CyriMarket-APK**
6. Installe le `.apk` sur ton téléphone Android (activer "Sources inconnues" dans les paramètres)

## Fonctionnalités de l'app

- Plein écran, pas de barre navigateur
- Barre de progression pendant le chargement
- Bouton retour Android navigue dans l'historique
- Sessions et panier préservés entre les visites
